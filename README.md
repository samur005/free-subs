# free-subs

Объединённая бесплатная подписка для ABS proxy и других клиентов (v2rayNG, Hiddify, Happ и т. п.).
Обновляется автоматически каждые 6 часов через GitHub Actions.

## Файлы

| Файл | Что внутри |
|---|---|
| `free_subs.txt` | все серверы из источников без дубликатов, по порядку приоритета (сначала списки для России) |
| `free_subs.b64` | то же в base64 |
| `free_subs_small.txt` / `.b64` | до 600 серверов, у которых прошла проверка TCP/TLS с серверов GitHub |

Проверка на GitHub не гарантирует, что сервер работает из вашей сети — в ABS после загрузки
серверы дополнительно проверяются настоящим соединением.

## Источники

Список и порядок — в `SOURCES` в `update_free_subs.py`. Чтобы добавить свою подписку, допишите строку
`("ссылка", 0)` (0 — брать целиком, число — сколько случайных серверов взять из большого списка).

Источники для России взяты по примеру приложения [YPtun](https://github.com/yanisplugg/yptun):

- [zieng2/wl](https://github.com/zieng2/wl) — небольшие списки под белые списки РФ (`vless_universal`, `vless_lite`);
- [igareck/vpn-configs-for-russia](https://github.com/igareck/vpn-configs-for-russia) — VLESS для белых списков мобильного интернета, CIDR и обхода блокировок;
- breead1337/ws-cache-9e41 (v.txt) — единый список «GitHub Page» из YPtun, берётся 1000 случайных
- [MahanKenway/Freedom-V2Ray](https://github.com/MahanKenway/Freedom-V2Ray) — общий агрегатор, берётся выборка до 250 серверов.

А также `sub.vlessfo.ru` (Tg: Vlessforu).

## Важно

Серверы публичные, их владельцы неизвестны и могут видеть ваш трафик. Используйте на свой риск,
не вводите через них пароли и платёжные данные.
